# Why make this app?

8/3/2026

This app has been an idea in the back of my mind for a few months.
I begin my senior year at RIT in 3 weeks, and I plan on using this app
as practice before I begin Senior Project and build a real-world app.

The utlimate goal of the Oscar's Life Operating System (OLOS)
is to build a suite of tools that I can use everyday to be facilitate my
everyday life. I already have a Finance Tracker app to track all of my
financial movements, and now I plan on building an app to track progress
towards my goals.

So apart from serving as a test run for Senior Project, I also plan on utilizing
this app in my everyday life. I have a lot of ambitions for my life, and this
app is to help me accomplish all of them.
