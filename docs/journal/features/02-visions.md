# Feature: Visions

8/3/2026

## Relational Hierarchy

```
Vision
│
├── Outcome
│     │
│     ├── Project
│     │      └── Tasks
│     │
│     └── Commitments
│            └── Tasks
│
└── Another Outcome
```

Vision → Where am I trying to go?
Outcome → What must become true?
Project → What do I need to build or complete?
Commitment → What kind of person am I choosing to be repeatedly?
Task → What do I do next?

## User Stories

### User

As a *User*, I want <capability>, so that <benefit>.

As a *User*, I want to declare [Visions](),
so that I can define my direction.

As a *User*, I want to create [Outcomes](),
so that I can identify the things that must be done to achieve a Vision.

As a *User*, I want to organize Outcomes,
so that I can envision a realistic path towards acheiving my Vision.

As a *User*, I want to create [Tasks](),
so that I can define actionable steps towards an Outcome.

As a *User*, I want to create weekly [Commitments](),
so I can take repeated steps towards an Outcome.

As a *User*, I want to be reminded of my Commitments every morning,
so that I can include them in my day's agenda.

As a *User*, I want to add Tasks to a Commitment,
so that I can remember important steps every time.

As a *User*, I want to create [Projects](),
so that I can make an organized effort to tackle a larger task.

As a *User*, I want to add Tasks to a Project,
so that I can define action steps towards completing the Project.

As a *User*, I want to mark a Project as complete,
so that I can retire the Project.

As a *User*, I want to reflect on my Commitments in the past week,
so that I can identify adjustments to my plan.

As a *User*, I want to reflect on my Tasks completed in the past week,
so that I can identify adjustments in my plan.
