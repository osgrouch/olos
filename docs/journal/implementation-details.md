# Pages

## Greeting Page

Should reuse the same 'Greeting' page component to display the morning and evening greetings.

## Qestions Page

Should reuse the same 'Questions' page/section component to display questions.

## Settings Page

  - Timezone
    - Controls the time displayed in the UI. Database should use UTC!
  - Morning Entry start time
    - The user can set at what time they want to automatically enter the morning entry on next load of the app.
    - So if the user sets this value to 6am, and they check the app at 1am, they will enter into the dashboard page for yesterday's entry.
  - Evening Entry start time
    - Same idea as above, but this time will be for the Evening Entry flow.
