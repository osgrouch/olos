# Product Principles

1. Define direction and take action
   - In order to make a journey, one must first decide on a destination.
2. Reduce friction and complexity
   - The easier it is to get started, the more likely that a user will begin and follow through.
3. Progress lies in consistency, not in perfection
   - Imperfect days are to be expected, but that is not a reason to stop moving forward.
4. Reviews provide accountability and help user derive and implement changes
   - Reviews provide the user a chance to reflect and evaluate their work over a set time period.
   - Reviews should help users identify changes and help users implement them.
5. Life is unpredictable and app should prioritize flexibility
   - Random life events happen and the app should readily support changes.
   - Reviews provide an opportunity to re-align the app with the intentions of the user and clean up old data objects.
6. The app should feel calm, never overwhelming
7. User should leave every session knowing what steps to take next
   - *Does this help someone take the next meaningful action?*
   - Every mountain is climbed one step at a time.
8. User data is confidential and never shared with anyone else
